# ThermalGraph Risk Analysis OS

博士论文配套的数据中心温度场预测与热风险可视分析原型。

## 功能

- TDC2.0 数据中心三维拓扑映射；
- 72 个温度节点的历史回放；
- 冻结 Main 模型的 1–60 min 温度轨迹查询；
- 当前温度和未来风险双图层接口；
- 研究审计、核查动作与记录导出；
- 桌面端和移动端响应式展示。

## 数据边界

公开演示包仅包含 2023-02-18 09:00–12:00 的有限回放窗口及其必要的历史、预测支撑区间。节点级风险概率与联合预测区间尚未接入真实归档模式，界面以“未接入”显示，不以零值或合成值替代。功能示例数据不作为论文实验结果。

## 部署

网站由 GitHub Actions 将 `docs/` 目录发布到 GitHub Pages。首次使用时，需要在仓库 **Settings → Pages** 中将 Source 设置为 **GitHub Actions**。
